# Dataset and manifest cells

Notebook cells 8, 11, 13, 14, 17, 18, 20, 21 are the source of truth for
the local dataset inventory, normalized manifest, 5h/1h split reuse, and
audio-header checks. Their exact code is preserved in `notebook_source_cells.py`
as a commented cell-index map. The notebook uses Drive paths and notebook
variables, so these cells are not standalone scripts.
